## Brand & Style

This design system expresses high-precision financial engineering fused with discreet private-banking luxury. Designed specifically for cross-border currency exchange, wealth transfer, and treasury oversight within Lusophone and global financial corridors, the visual identity prioritizes clarity, structural integrity, and confidence.

The design philosophy combines **Modern Corporate Precision** with subtle **Glassmorphic Depth** and **Tonal Layering**:
- Deep slate and midnight indigo foundational surfaces establish authority and eliminate eye fatigue during high-frequency tracking.
- Luminous emerald and crisp mint accents celebrate positive market movements, liquidity yields, and successful transactions.
- Fine hairline borders and calibrated backdrop blurs evoke optical glass instruments and executive digital terminals.
- All information architecture respects Brazilian Portuguese and European Portuguese syntax, accommodating variable label lengths without truncation or visual distortion.

## Colors

The palette is tuned specifically for high-contrast legibility in a dark canvas environment, ensuring swift financial scanning and instant recognition of delta shifts:

- **Primary (`#10B981` — Esmeralda Câmbio):** Anchors primary conversions, positive market yields, action confirmations, and key metric progress.
- **Secondary (`#6366F1` — Índigo Real):** Used for platform infrastructure elements, transfer routes, multi-currency wallet hubs, and non-directional interactive controls.
- **Tertiary (`#14B8A6` — Turquesa Liquidez):** Supports cross-currency pairs, secondary rate benchmarks, and real-time live ticker indicators.
- **Neutral Surface Palette:**
  - Canvas Base: `#0B0F19` (Deep Obsidian Indigo).
  - Elevated Container / Surface Tier 1: `#111827` (Midnight Slate).
  - Elevated Interactive / Surface Tier 2: `#1E293B` (Refined Slate).
  - Border & Dividers: `rgba(148, 163, 184, 0.12)` to `rgba(148, 163, 184, 0.24)`.
- **Feedback & Delta Tones:**
  - Positivo / Ganho: `#10B981` (Emerald).
  - Negativo / Queda: `#F43F5E` (Crimson Rose).
  - Alerta / Spread: `#F59E0B` (Amber Gold).
  - Neutro / Estável: `#94A3B8` (Muted Slate).

## Typography

The typographic hierarchy couples **Plus Jakarta Sans** for prominent titles, value propositions, and summary cards with **Inter** for dense transactional tables, conversion inputs, and analytical labels.

- **Tabular Numerics:** All currency indicators, foreign exchange ratios (e.g., `USD/BRL 5,4230`), timestamp tickers, and monetary sums must strictly enable CSS font features `font-feature-settings: 'tnum' on, 'cv05' on, 'zero' on`. This eliminates horizontal jitter during real-time streaming updates.
- **Portuguese Language Considerations:** Text containers allocate up to 25% additional horizontal space relative to English defaults to naturally accommodate terms such as "Transferência Internacional", "Taxa de Câmbio Comercial", and "Comprovante de Operação" without artificial truncation.

## Layout & Spacing

A responsive 12-column fluid grid system governs dashboards and currency balance interfaces:

- **Desktop (≥ 1280px):** 12 columns, `1.75rem` (`gutter-lg`) gutters, `3rem` (`margin-lg`) margin. Two-column conversion mechanics (source wallet input beside target wallet readout) with a centralized sticky transaction summary panel.
- **Tablet (768px – 1279px):** 8 columns, `1.25rem` (`gutter`) gutters, `2rem` (`margin`) margin. Market trends and quick-swap mechanisms stack vertically while retaining persistent multi-currency balances.
- **Mobile (≤ 767px):** 4 columns, `0.75rem` (`gutter-sm`) gutters, `1rem` (`margin-sm`) margin. Conversion flows transition into single-step directional workflows with fixed bottom action triggers.
- **Component Geometry:** Inner form controls, input pairings, and currency selector chips adhere to an 8px spatial grid, while micro-elements (tag paddings, badge icons) align along a strict 4px sub-grid.

## Elevation & Depth

Visual hierarchy leverages high-refraction glassmorphism balanced with calibrated hairline boundaries:

- **Base Ground (`#0B0F19`):** Non-elevated system foundation.
- **Surface Level 1 (Wallets & Metric Panels):** Background set to `rgba(17, 24, 39, 0.85)` with `backdrop-filter: blur(12px)`. Enclosed by a crisp border: `1px solid rgba(148, 163, 184, 0.1)`. Soft ground shadow: `0 4px 20px -2px rgba(0, 0, 0, 0.4)`.
- **Surface Level 2 (Swap Calculators & Modal Sheets):** Background set to `rgba(30, 41, 59, 0.9)` with `backdrop-filter: blur(16px)`. Border: `1px solid rgba(148, 163, 184, 0.2)`. Cast shadow: `0 12px 32px -4px rgba(0, 0, 0, 0.5), 0 0 0 1px rgba(255, 255, 255, 0.04) inset`.
- **Interactive Focus / Rate Highlight:** Elements featuring active spreads or gain signals utilize an atmospheric radial glow: `0 0 24px -4px rgba(16, 185, 129, 0.25)`.
- **No Heavy Drop Shadows:** Deep dark backgrounds utilize luminous edge highlights (`rgba(255, 255, 255, 0.05)` top borders) rather than black silhouettes to establish physical altitude.

## Shapes

The design system standardizes on **Rounded (Level 2)** geometry:
- Standard inputs, buttons, rate badges, and dropdown triggers utilize `0.5rem` (8px).
- Complex cards, wallet balance modules, and transaction groups use `rounded-lg` (`1rem` / 16px).
- Full conversion workflow sheets and dialogs scale to `rounded-xl` (`1.5rem` / 24px).
- Currency indicator tags and user avatars adopt complete pill geometry (`rounded-full`) to contrast against the structured rectilinearity of data tables.

## Components

### Buttons
- **Primary ("Converter Agora", "Confirmar Envio"):** High-luminance Emerald background (`#10B981`) with rich obsidian typography (`#062E20`), bold weight, 8px corners. Subtle gradient sheen (`linear-gradient(180deg, rgba(255,255,255,0.15) 0%, rgba(255,255,255,0) 100%)`). Hover transitions to `#059669` with an emerald ambient glow.
- **Secondary ("Ver Detalhes", "Cancelar"):** Surface layer slate background (`rgba(255, 255, 255, 0.06)`), 1px hairline border (`rgba(148, 163, 184, 0.2)`), crisp white text (`#F8FAFC`). Hover illuminates border to primary accent.
- **Icon Actions (Swap Currency Button):** 40x40px circular or 8px rounded interactive module with a 180-degree rotational animation on click.

### Currency Input Fields & Calculators
- Dual-segment input cards: Left side holds raw numerical balance input (large tabular typography, no border on the number field itself), right side anchors the interactive currency selector pill (`BRL`, `USD`, `EUR`) accompanied by high-res country flag icons and a subtle downward chevron.
- Active input state triggers a 1px border highlight in `#10B981` accompanied by a localized inner glow. Subtext immediately displays live counter-values (e.g., "1 USD = 5,4235 BRL • Spread zero").

### Exchange Rate Badges & Tickers
- **Taxa Positiva (Gain):** Emerald-tinted background (`rgba(16, 185, 129, 0.12)`), text `#34D399`, containing an upward vector arrow and tabular delta (e.g., `+1,42%`).
- **Taxa Negativa (Loss):** Rose-tinted background (`rgba(244, 63, 94, 0.12)`), text `#FB7185`, containing a downward vector arrow.
- Border radius is fixed at pill shape with 4px vertical and 8px horizontal padding.

### Cards & Wallets
- Glassmorphic panels with dark indigo substrate, delicate outer hairline border, and a subtle light reflection along the top interior border.
- Each wallet card displays: ISO currency code, national denomination title ("Real Brasileiro"), available liquidity balance in tabular format, and a one-click "Converter" trigger.

### Checkboxes & Radio Controls
- Rounded 4px check boxes and circular radio elements framed in `rgba(148, 163, 184, 0.3)`. Checked state fills with `#10B981` displaying a crisp dark glyph checkmark.

### Lists & Transaction History
- Borderless row separators utilizing `rgba(148, 163, 184, 0.08)`.
- Left-aligned currency icon with transaction type description ("Remessa Comercial para Conta Exterior") and localized timestamp ("Hoje às 14:32").
- Right-aligned tabular numeric values with explicit directional color coding: outflows in `#F8FAFC`, inflows in `#10B981`.
